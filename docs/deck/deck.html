The problem

A code is run entirely by voice, and orders get lost.

26%of 387 spoken orders in 89 filmed resuscitations were closed-loop (repeated back).El-Shafy et al., J Surg Educ 2018
3.6×faster completion of orders that were closed-loop.Same study, HR 3.6 (95% CI 2.5–5.3)
κ 0.27agreement between hospital records and observers on epinephrine timing.J Clin Med 2023, cardiac ICU arrests

Hands are on the chest, the airway and the syringes. Someone must stop patient care to write. Tap-based recorder apps still need free hands, and nothing notices an order that nobody confirmed.

What CodeLoop does

Every order becomes a loop that must close.

1 · Ordered“Give one milligram of epinephrine.”
2 · Read back“Epi one milligram, drawing up.”
3 · Given“Epi's in.”
Silence for 10 s → amber · 15 s → spokenNobody confirmed the order.
“Epinephrine one milligram ordered. Not acknowledged.”
Different value read back → redOrdered 300 mg · read back 150 mg
“Check dose. Ordered amiodarone three hundred milligrams, read back one hundred fifty milligrams.”

It also runs the ACLS clock out loud: 2-minute cycles, the epinephrine window, shocks and a shockable-rhythm check. It answers “CodeLoop, last epi kab diya tha?” from its own record.

After the code · closing the learning loop

The debrief every mock code should have, in minutes.

  • Quality vs AHA targets: first shock, first epinephrine, read-back rate and time, estimated CPR fraction. A dashboard tracks them across codes.
  • Second listen: AssemblyAI async Universal-3.5 Pro re-transcribes the whole recording and confirms each live event, or flags it for review. 13 of 13 confirmed
  • Spoken debrief: a hands-free Voice Agent conversation with tool calls. It quotes facts from the record, never computing them, and saves the team's lessons in their own words.

How it works

Models understand speech. Deterministic code decides.

AssemblyAI · ears

U3.5 Pro Streaming

Room audio from a crash-cart tablet. Speaker labels, Medical Mode, ACLS keyterms, far-field Voice Focus, English + Hindi.

CodeLoop core

Grammar → resolver → ACLS engine

Every event quotes the exact words it came from. Loops, timers, flags and every spoken number come from unit-tested, replayable code. The model never picks a dose.

AssemblyAI · voice

Voice Agent API

Speaks fixed lines only, waits for a gap in the room, stops when a clinician talks over it. Never hears the room's chatter.

Every utterance, event, loop, flag and spoken line → a SHA-256 hash-chained audit log. The Code Record is rebuilt from it, so the screen and the record cannot disagree.

Safety by design

Built so that being wrong is visible, not silent.

  • Low ASR confidence on a dose → UNCONFIRMED, never a fact
  • Read-back differs → red card, one-tap confirm, spoken check
  • A misheard “ROSC” only pauses timers; a human ends the code
  • CodeLoop's own voice is recognised and never logged as the team
  • Never recommends treatment: it reminds timing, never what to give
  • Answers come from the record: a managed LLM chose the wrong fact in testing, so answers are composed deterministically
  • Tamper-evident record with integrity check and head hash
  • Screen-only / timers-only / mute: the team decides how chatty it is
